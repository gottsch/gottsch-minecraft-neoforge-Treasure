Keys open [Locks](entry:locks). To use one, **sneak + use** it on a locked chest. Hover over a key in your inventory to
see what it opens and how many uses it has left.

- **Uses:** every key wears out. The numbers here are the defaults; a server can change them.
- **Breakable** keys can snap when an unlock fails.
- **Merging:** keys don't stack, but two of the same key can be merged in an anvil. The new key has both keys' uses
  added together, up to 1000.

Carrying a lot of keys? Put them on a [Key Ring](entry:key_ring).

## Special Keys {#special}

### Ember Key {#ember_key}

Opens the Ember Lock, and the Wood and Leaf Locks too, burning them away as it does.

### Lightning Key {#lightning_key}

Opens every **Elemental** lock.

### Metallurgists Key {#metallurgists_key}

Opens every **Metal** lock.

### Jewelled Key {#jewelled_key}

Opens every **Gems** lock.

### Skeleton Key {#skeleton_key}

Opens any Common, Uncommon, Scarce or Rare lock, except the Wither Lock.

### The One Key {#one_key}

Opens every lock, every time. It never wears out.

### Bone Key {#bone_key}

Opens the [Bone Chest](entry:chests#bone_chest). Use it again on an unlocked Bone Chest to lock it.
